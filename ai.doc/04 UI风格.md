# UI 风格指南 (TimeFlow Design System)

## 1. 核心视觉理念
*   **极简主义 (Minimalism)**: 彻底消除多余元素，仅保留时间、任务标题和操作。
*   **扁平化 2.0 (Glassmorphism & Soft Shadows)**: 使用马卡龙色系背景配合弥散阴影，局部利用 `backdrop-filter` 增强穿透感。
*   **信息层级 (Visual Hierarchy)**: 通过卡片、阴影和垂直轴线建立清晰的视觉逻辑。

## 2. 核心视觉特征
### 色彩方案 (Pastel Palette)
以白色和浅灰 (`--tf-bg-secondary`) 为基调，配合低饱和度、高明度的色彩：
*   **天空蓝 (`--tf-primary`)**: 系统主色，用于主要动作和标题标记。
*   **淡绿 (`--tf-accent-green`)**: 成功、完成状态、正在进行中的波纹。
*   **淡黄 (`--tf-accent-yellow`)**: 暂停状态、当日统计高亮。
*   **淡粉 (`--tf-accent-pink`)**: 危险动作（删除）、警告。

### 统一轴线对齐 (100px Alignment Axis)
为了实现极致的垂直整齐度，全系统采用 **100px** 逻辑轴线：
*   **Header**: 时间显示区域固定宽 100px。
*   **Checkpoint**: 条目左侧预留 24px 槽位（放置 Sub-dot），右侧内容区的时间列固定宽 100px。
*   **Session**: 虽然布局略有不同，但整体重心依然向此轴线靠拢。
*   **结果**: 无论在任务描述中还是 Checkpoint 列表中，所有的记录时间点在视觉上都是完美垂直对齐的。

### checkpoints 格栅化布局
CheckpointItem 不再使用简单的弹性布局，而是采用“槽位 (Slot) + 内容 (Content)”的双列格栅化结构：
*   **Slot**: 24px 宽，内嵌 Sub-dot，作为主时间轴的支线。
*   **Content**: 包含 100px 时间列 + 弹性内容列，实现内容与时间的完美分离。

## 3. 交互特征 (UX Details)
*   **响应式卡片**: 任务卡片 (`.tf-card`) 在悬浮、选中和进行中具有不同的阴影和边框表现。
*   **微动画**:
    *   **进行中状态**: 指示点 (`.tf-timeline-dot.active`) 具有呼吸灯效果。
    *   **按钮反馈**: 所有按钮点击具有微缩放效果 (`scale(0.96)`)。
*   **快捷键驱动**: 所有的设计都考虑到无鼠标操作的可能性，选中状态有明显的边框高亮。

## 4. UI 规范
*   **文字**: 字体大小不小于 `1rem`，全局启用 `-webkit-font-smoothing: antialiased` 解决文字模糊。
*   **圆角系数**: 遵循 `8px` / `12px` / `16px` / `9999px` (Full) 的阶梯。
*   **高度规范**: 常规按钮统一高度为 `36px`。
