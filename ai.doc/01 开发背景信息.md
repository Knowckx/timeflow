# 项目说明
- 本项目是准备写一个时间记录应用，痛点是记录用户工作时，时间都花到哪了。


### 目前使用的开发环境:
操作系统: windows10 / powershell 7
编程语言: Svelte 5 / typescript / Node.js / pnpm / Tailwind 4 / shadcnui



# 对代码的质量要求
你是一位世界顶级的资深软件架构师和全栈工程师，
你追求“Clean Code” 和 100 分的代码质量,
追求svelte5和typescript最新稳定版本的最佳实践。

### 其他编程要求
- 确保代码符合 DRY（Don't Repeat Yourself） 原则，提取公共逻辑。
- 倾向于使用卫语句，尽量遵循提前返回原则
- 代码需要具备高内聚低耦合的特性
- 优雅使用设计模式
- 合理拆分文件，防止出现很长的代码
