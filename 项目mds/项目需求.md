# 项目需求说明
我准备写一个时间记录应用，痛点是记录用户工作时，时间都花到哪了。
前期包含如下的功能点: 

### 功能1 项目初始化
- 建立主题风格的独立配置文件，方便后续进行项目UI风格的切换


### 功能2 记录工作的时间线
```
├─  10:00 任务: 写代码 -> 15:00 完成 任务用时 00:40:00
├────  10:00 任务被创建啦！(下面放此任务的详细日志) 
├────  10:10 任务开始（用户点击开始）--> 10:15 暂停（用户点击暂停 本次投入时间5分钟）
├──────  10:12 Checkpoints 中间记录点(用户可以插入Checkpoints)
├──────  10:14 Checkpoints 中间记录点
├────  10:30 继续（用户点击继续） --> 11:00 完成（用户勾选完成 本次投入时间30分钟）
├──────  10:35 Checkpoints 中间记录点
├──────  10:50 Checkpoints 中间记录点
├─  xx:xx 其他任务
├─  xx:xx 其他任务
```
- 任务层级 任务 > 工作时段 > Checkpoint
- 每个工作时段包含所属任务，开始时间，结束时间，Checkpoints，工作时长。
- 创建任务后是 待开始 状态
- 不允许在暂停时添加 Checkpoint
- 单任务规则 用户同时只有一个任务正在进行
- 鼠标移到某个任务时，这个任务栏hover，并且出现一个按钮 状态分别是 开始/暂停/继续


### 功能3 日期与日历
- 用户打开app后 会自动跳转到当前日期(场景是每天的00.00需要跳转到新的一天)
- 在主页的日期边上添加两个箭头 每次点击可以切换到昨天/明天的数据


### 功能4 导出
每日完成的事件可以用md/text格式导出，方便用户把自己的工作记录复制到自己的笔记本
```
# 2024年5月20日 星期一

## 🚀 核心工作
- [x] 10:00 - 11:30 | 编写 Life-Flow 核心代码 #Dev (用时 1h30m)
    > 解决了时间戳计算的 Bug，感觉很爽。

## 🌟 生活点滴
- [x] 喝水打卡：5/5 杯
```
