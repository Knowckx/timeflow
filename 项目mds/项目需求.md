# 项目需求说明
我准备写一个时间记录应用，痛点是记录用户工作时，时间都花到哪了。
前期包含如下的功能点: 

### 功能 v0.01 项目初始化
- 建立主题风格的独立配置文件，方便后续进行快速切换风格



### 功能 v0.1 记录日常工作的时间线
```
|-12:15:09 开始做事件1 ->14:09:12 完成    用时 00:55:00 (当我打上钩之后会计算出这个项目实际使用的时间)
|	  13:40:29 Checkpoints 事件1中间记录点1 
|	  13:45:00 Checkpoints 事件1中间记录点2  
|	
|-15:00:23 开始做事件2 -> 15:36:36  用时 00:36:00
|-20:23:36 正在做事件3
```
- 用户点击输入框，添加下面将要做的工作任务。我们记录此时的时间，并且展示出来。
- 用户可以为这个任务插入Checkpoints
- 用户勾选任务完成后，展示结束时间和所用的时间



### 功能 v0.2 导出
每日完成的事件可以用md/text格式导出，方便用户把自己的工作记录复制到自己的笔记本
```
# 2024年5月20日 星期一

## 🚀 核心工作
- [x] 10:00 - 11:30 | 编写 Life-Flow 核心代码 #Dev (用时 1h30m)
    > 解决了时间戳计算的 Bug，感觉很爽。

## 🌟 生活点滴
- [x] 喝水打卡：5/5 杯
```
