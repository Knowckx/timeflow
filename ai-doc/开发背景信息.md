# 开发背景信息

我的开发环境如下:
windows10 / Svelte 5 / typescript / Node.js / pnpm / tailwindcss / shadcnui

技术问题有几个细节需要注意:
- 尽量以现代的最佳实践来处理编程问题
- 我给你的代码中，假如有未知的定义，那先注释TODO，不用自己去实现
- 假如你只是部分修改了一个文件，只展示有修改的部分
- 假如一个文件或者函数太长可以考虑合理拆分
- 编码时，我倾向于使用卫语句，尽量遵循提前返回原则
